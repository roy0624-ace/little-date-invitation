# 给你的一封小邀请

一个不依赖框架或外部服务的手机优先约会邀请页，适合通过微信发送。

收到邀请的人可以依次选择约会活动、晚餐菜系和具体口味，再确认完整计划。活动包含咖啡店、电影、公园散步、自驾游、野餐、看展、书店、桌游等；餐饮包含中餐、西餐、日料、韩餐、火锅、烧烤、甜品轻食等类别，并提供地区菜系和具体食物选项。活动和晚餐口味都支持填写自定义想法。

## 本地预览

直接用浏览器打开 `index.html` 即可预览和定制内容。浏览器会提示：本地文件地址不能作为邀请链接发送。

## 生成微信可打开的链接

把 `index.html` 发布到一个公开的 HTTPS 静态网页地址。发布后打开该网页，点右上角「定制邀请」，填写称呼、邀请附言和时间，再复制生成的专属链接，粘贴到微信对话框发送。

例如，可把文件放进 GitHub 仓库根目录，并用 GitHub Pages 发布。启用 Pages 后得到的 `https://用户名.github.io/仓库名/` 地址可直接打开本页。

链接中的称呼和附言通过网址参数传递；页面不会把内容上传或保存到服务器。对方选择的约会安排仅在当前页面中用于显示，并会写进答应后的回复，方便复制发回给邀请者。每一步都保留了认真拒绝的入口。
