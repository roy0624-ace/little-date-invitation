# Would you be my special date?

一个不依赖框架或外部服务的手机优先约会邀请页，适合通过微信发送。主题是 “Would you be my special date?”，页面用猫咪贴纸、立体软糖按钮、弹跳选项、爱心粒子和逐步变化的求情文案，给点击即时反馈。

收到邀请的人可以依次选择约会活动、晚餐菜系、具体口味和约会日期时间，再确认完整计划。最终页展示所有选择，并附上「真开心你没有拒绝！我会准时来接你的。」活动包含咖啡店、电影、公园散步、自驾游、野餐、看展、书店、桌游等；餐饮包含中餐、西餐、日料、韩餐、火锅、烧烤、甜品轻食等类别，并提供地区菜系和具体食物选项。活动和晚餐口味都支持填写自定义想法。

## 本地预览

直接用浏览器打开 `index.html` 即可预览和定制内容。浏览器会提示：本地文件地址不能作为邀请链接发送。

## 生成微信可打开的链接

把 `index.html` 发布到一个公开的 HTTPS 静态网页地址。发布后打开该网页，点右上角「定制邀请」，填写称呼、邀请附言和时间，再复制生成的专属链接，粘贴到微信对话框发送。

例如，可把文件放进 GitHub 仓库根目录，并用 GitHub Pages 发布。启用 Pages 后得到的 `https://用户名.github.io/仓库名/` 地址可直接打开本页。

链接中的称呼和附言通过网址参数传递；页面不会把内容上传或保存到服务器。对方选好约会安排后，确认页会展示活动、晚餐、日期和时间；点击答应或认真拒绝会先复制对应回复，再尝试关闭微信内的邀请页返回聊天。若当前浏览器不允许网页关闭，结果页会提示手动返回并粘贴；若自动复制不可用，也会显示回复文字供长按复制。每一步都保留了认真拒绝的入口。
